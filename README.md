# Safe Haven 🌿
> **พื้นที่ปลอดภัยสำหรับทุกความรู้สึก (A Safe Place for Your Feelings)**

Safe Haven คือเว็บแอปพลิเคชันที่ออกแบบมาเพื่อเป็นพื้นที่พักใจและรับฟังความรู้สึกของผู้ใช้อย่างอ่อนโยน ปราศจากการตัดสิน ไม่มีการเก็บข้อมูลส่วนตัว และไม่ใช้การวินิจฉัยทางการแพทย์

---

## ✨ คุณสมบัติเด่น (Features)

1. **ระบบตอบกลับระหว่างการสนทนา (Conversational Response System - Prompt 03):**
   - รูปแบบคล้าย Chat Interface ที่มี Safe Haven คอยรับฟัง
   - แสดงข้อความตอบกลับที่สัมพันธ์กับคำตอบของผู้ใช้ในทุกข้อความก่อนถามคำถามถัดไป
   - ใช้ถ้อยคำสะท้อนความรู้สึกอย่างอ่อนโยน เช่น *"จากสิ่งที่คุณเล่า..."*, *"ฟังดูเหมือนว่า..."*
   - แอนิเมชันจำลองจังหวะการรับฟัง (Typing Indicator) ให้ความรู้สึกเป็นธรรมชาติ
   - สามารถย้อนกลับไปแก้ไขคำตอบได้ และระบบจะคงคำตอบเดิมไว้
   - เมื่อเปลี่ยนคำตอบ ข้อความตอบกลับและเส้นทางคำถาม (Branching) จะปรับเปลี่ยนตามทันที

2. **ระบบคำถามสำรวจใจแบบแตกแขนง (Branching Questionnaire):**
   - 5 หมวดปัญหาหลัก: การเรียน, ความรัก, ครอบครัวและเพื่อน, ความรู้สึกส่วนตัว, ชีวิตและอนาคต
   - คำถามต่อเนื่อง 5 ข้อที่เจาะลึกอย่างอ่อนโยน พร้อมหน้าสรุปผลสะท้อนใจและคำแนะนำเล็ก ๆ ที่นำไปใช้ได้จริง

3. **เช็กความรู้สึกเร่งด่วน (Quick Mood Check):**
   - การ์ดสำรวจอารมณ์ 6 รูปแบบ (เหนื่อยล้า, เศร้า, เครียด, โดดเดี่ยว, สับสน, หมดกำลังใจ) สำหรับผู้ที่ต้องการข้อความปลอบโยนในทันที

4. **ข้อความให้กำลังใจและสายด่วนช่วยเหลือ (Support & Crisis Helpline):**
   - ข้อความโอบกอดใจและช่องทางติดต่อสายด่วนสุขภาพจิต (1323) และสะมาริตันส์ (02-113-6789)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **HTML5 & Semantic Markup**

- **Google Fonts:** Prompt & Nunito

## 🚀 วิธีการใช้งาน (Getting Started)

เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้โดยไม่ต้องติดตั้งเซิร์ฟเวอร์หรือฐานข้อมูล

```bash
# Clone repository
git clone https://github.com/pudtipung/SafeHaven.git

# เข้าสู่โฟลเดอร์โปรเจกต์
cd SafeHaven

# เปิดใช้งานในเบราว์เซอร์ (หรือดับเบิลคลิก index.html)
start index.html
```
